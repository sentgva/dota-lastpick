# Dota 2 Last Pick — бриф на дизайн

Telegram Mini App: помощник по драфту. Пользователь выбирает героев соперника и своих
союзников — приложение показывает, кого взять последним пиком и что покупать против
этого драфта.

Логика и данные уже реализованы. Этот документ описывает **структуру и содержание
экранов**, чтобы дизайн лёг на готовые компоненты.

---

## 1. Контекст использования — главное ограничение

Приложением пользуются **во время фазы драфта Dota 2**, когда на пик остаётся 20–40 секунд.
Человек держит телефон в одной руке, вторая на клавиатуре, взгляд рвётся между экраном
телефона и монитором.

Из этого следует всё остальное:

- **Скорость считывания важнее красоты.** Ответ «кого брать» должен читаться за 2 секунды,
  без прокрутки и без чтения текста.
- **Крупные тач-таргеты.** Минимум 44×44 pt. Промах по слоту героя стоит пика.
- **Никаких анимаций входа, задержек, плавных раскрытий дольше 150 мс.**
- **Плотность.** На экране должно помещаться 5 слотов врага + 4 союзника + минимум
  3 рекомендации без скролла на экране 390×844.
- Тёмная тема — основная. Приложение открывают поверх тёмного клиента игры ночью.

---

## 2. Платформенные рамки (Telegram Mini App)

- Ширина от **320 до 440 px**, дизайн вертикальный. Планшет и десктоп — тот же макет
  с максимальной шириной контента ~720 px по центру.
- Сверху системный хедер Telegram (~56 px) — свою шапку с названием приложения делать
  **не нужно**, это дублирование.
- Снизу safe area на устройствах с домашним индикатором — нижний отступ контента 40 px.
- Telegram передаёт тему пользователя в CSS-переменные, они уже проброшены:
  `--tg-bg-color`, `--tg-secondary-bg-color`, `--tg-text-color`, `--tg-hint-color`,
  `--tg-button-color`. Палитра должна **строиться на них**, а собственные цвета
  использовать только там, где нужен смысловой сигнал (см. §6).
- Внутренняя навигация — только вкладки. Никаких «назад» в браузерном смысле.

## 3. Карта экранов

```
┌─ Вкладки (sticky сверху): [ Драфт ] [ Билды ]
│
├─ A. ДРАФТ  ─────────────────────────────────────────
│    A1. Сетка слотов соперника (5)
│    A2. Сетка слотов своей команды (4)
│    A3. Панель контролов (ранг · роль · веса · сброс)
│    A3a. Панель весов (раскрывается, 3 слайдера)
│    A4. Список рекомендаций (карточки, топ-15)
│    A4a. Карточка в раскрытом виде (разборка + билд)
│    A5. Оверлей выбора героя (шторка снизу)
│
└─ B. БИЛДЫ ─────────────────────────────────────────
     B1. Сетка всех героев + поиск
     B2. Экран героя: закуп по фазам + блок «против драфта»
```

**Артборды, которые стоит нарисовать** (порядок = приоритет):

1. A — Драфт, пустое состояние (ничего не выбрано)
2. A — Драфт, заполненный: 5 врагов, 4 союзника, список рекомендаций
3. A4a — карточка рекомендации в раскрытом виде
4. A5 — шторка выбора героя
5. B2 — экран героя с билдом и блоком «против драфта»
6. B1 — сетка героев
7. A3a — панель весов
8. Состояния: загрузка / ошибка API / пустой результат

## 4. Экран A — Драфт

### A1–A2. Слоты драфта

Две группы, визуально **противопоставленные** — это первое, что считывает глаз:

| | Соперник | Своя команда |
|---|---|---|
| Заголовок | «Драфт соперника» | «Ваша команда (4 союзника)» |
| Слотов | 5 | 4 |
| Смысл | угроза | ресурс |

Слот — прямоугольник с портретом героя (исходник 256×144, соотношение 16:9),
подписью-именем и крестиком очистки в углу. Пустой слот — плейсхолдер с «+».

Сейчас группы различаются цветом рамки (красный / зелёный). **Цвет не должен быть
единственным различителем** — нужна форма, позиция или метка, иначе группы сливаются
у дальтоников и при ярком свете.

Ключевой вопрос к дизайну: 5-й слот своей команды отсутствует намеренно — это и есть
место, которое подбирает приложение. Стоит показать его как **пустое место
с рекомендацией**, а не просто отсутствие слота: пользователь должен физически видеть
дыру, которую закрывает.

### A3. Контролы

Одна строка, четыре элемента: селект ранга (9 значений: Все ранги, Herald … Immortal),
селект роли (Любая, Carry, Support, Initiator, Disabler, Nuker, Durable, Escape, Pusher),
кнопка «Веса», кнопка «Сброс».

Это **второстепенный слой** — настраивается один раз и не трогается. Не должен
конкурировать за внимание с рекомендациями. «Сброс» — деструктивное действие,
не ставить вплотную к часто нажимаемым элементам.

### A3a. Панель весов (скрыта по умолчанию)

Три слайдера, диапазон 0–2 с шагом 0.1, показывают текущее значение:
**Контрпик** (1.0), **Синергия** (0.5), **Мета** (0.8).

Для продвинутых. Раскрывается по кнопке «Веса».

### A4. Карточка рекомендации — центральный объект всего приложения

Свёрнутая карточка содержит:

```
[ранг]  [портрет]  Имя героя            [+2.47]
                   Carry · Escape · Nuker
        ─────────────────────────────────────
        Контрпик  ▓▓▓▓▓▓░░░░░░  +3.10
        Синергия  ▓▓▓░░░░░░░░░  +1.50
        Мета      ░░▓▓░░░░░░░░  -0.40
```

- **Ранг** (1, 2, 3…) — порядковый номер в списке.
- **Портрет** героя, 16:9.
- **Имя** + роли мелким кеглем.
- **Итоговая оценка** — число со знаком, 2 знака после запятой. Типичный диапазон
  **от −5 до +8**. Это главное число карточки.
- **Три полосы вклада** — контрпик, синергия, мета. Каждая может быть отрицательной,
  поэтому полоса растёт **от центра**: вправо — плюс, влево — минус. Шкала ±8.

Три полосы — это объяснение «почему». Именно они отличают приложение от списка
«просто возьми вот этого». Но их три штуки × 15 карточек = 45 полос на экране;
задача дизайна — сделать их читаемыми и при этом не шумными. Возможно,
в свёрнутом виде хватит одной составной полосы, а разбивка раскрывается.

Карточка кликабельна целиком — раскрывается A4a.

### A4a. Раскрытая карточка

Добавляется под полосами:

1. **Заметка о роли** (если есть): «закрывает роль Support, у команды нет магического урона».
2. **«Против кого работает»** — список выбранных врагов: имя, винрейт против него (`54.2%`)
   и скорректированное преимущество (`+2.10`). Отсортировано по убыванию пользы.
   Здесь важно: винрейт и преимущество — **разные числа**, их нельзя путать, нужна
   визуальная разница.
3. **«Комбо с союзниками»** — имя союзника + текстовая причина
   («RP собирает пачку под God's Strength»). Это единственное место с полноценным текстом.
4. **Блок билда** (тот же компонент, что на экране B2): закуп по фазам + «против драфта соперника».

Раскрытая карточка длинная. Нужно решить, как пользователь возвращается к списку:
свернуть кликом, закрепить заголовок или что-то ещё.

### A5. Оверлей выбора героя

Шторка снизу (до 85% высоты экрана), поверх затемнения:

- Заголовок: «Выберите вражеского героя» / «Выберите союзника» + кнопка «Закрыть».
- Поле поиска, автофокус.
- Сетка героев: карточки минимум 72 px шириной, портрет 16:9 + имя.
- Без поискового запроса герои отсортированы **по популярности** в выбранном ранге —
  нужный обычно в первых рядах.
- Уже занятые герои показаны приглушёнными и не нажимаются.

Это самый частый экран взаимодействия: девять раз за драфт. Ради него стоит
пожертвовать красотой в пользу скорости — крупная сетка, мгновенный отклик,
шторка открывается снизу под большой палец.

## 5. Экран B — Билды

### B1. Сетка героев

Поиск + та же сетка портретов, что в A5, но на всю страницу. Сортировка по популярности.

### B2. Экран героя

- **Шапка**: крупный портрет, имя, роли, базовый винрейт в выбранном ранге.
- **Тумблер** «Учитывать драфт соперника (Pudge, Lion, …)» — появляется, только если
  на вкладке «Драфт» уже выбраны враги.
- **Популярный закуп** — 4 секции по фазам: **Старт**, **Ранняя игра**, **Середина**,
  **Поздняя игра**. В каждой до 8 предметов в горизонтальном скролле.
  Предмет = иконка 88×64, название, число закупов (`12.4k`).
- **«Против драфта соперника»** — отдельный блок с видимой границей:
  - Чипы угроз: «невидимость · 3 героя», «магический бёрст · 2 героя», «хил и реген · 1 герой».
    Всего 11 возможных категорий: невидимость, хил и реген, иллюзии и суммоны,
    магический бёрст, сильная правая рука, уклонение, длинный контроль, сайленс,
    ключевые пассивки, резкое сближение, сжигание маны.
  - Ряд рекомендованных предметов, отсортированных по важности.
  - Список из 5 строк с объяснением: «**Pipe of Insight** — щит от магии на всю команду
    (Lina, Zeus)».

Блок «против драфта» — вторая по ценности вещь в приложении после рекомендации пика.
Сейчас он визуально слабее популярного закупа, хотя должен быть сильнее: популярный
закуп можно посмотреть где угодно, а этот блок — нет.

## 6. Цвет и смысл

Цветом кодируются **три разные вещи**, и их нельзя смешивать:

| Смысл | Где | Сейчас |
|---|---|---|
| Сторона: враг / союзник | слоты драфта, чипы угроз | красный / зелёный |
| Знак числа: польза / вред | оценки, полосы вклада, винрейты | зелёный / красный |
| Акцент интерфейса | активная вкладка, заметки | цвет кнопки Telegram |

Это конфликт: красная рамка слота врага и красное отрицательное число означают
разное. Развести их — задача дизайна.

Требования:

- Знак числа дублируется **не только цветом** — знак `+`/`−`, направление полосы,
  позиция. Красно-зелёная пара недоступна ~8% мужчин, а аудитория Dota 2 — почти
  сплошь мужчины.
- Контраст текста не ниже 4.5:1, мелких подписей (9–11 px сейчас) — выше.
- Палитра должна пережить как светлую, так и тёмную тему Telegram.

## 7. Типографика и плотность

Сейчас используются кегли 9, 11, 12, 13, 14, 18 px — это слишком дробная шкала,
собранная по месту. Нужна нормальная шкала с 4–5 ступенями.

Отдельная проблема: **9 px** на подписях предметов, имён в слотах и ячейках сетки.
Это ниже читаемого минимума. Либо увеличивать, либо менять способ подачи
(тултип, сокращение, отказ от подписи там, где иконка узнаваема).

Числа (оценки, винрейты, счётчики) — **моноширинные цифры** (`font-variant-numeric:
tabular-nums`), иначе колонки прыгают при обновлении.

## 8. Состояния, которые нужно нарисовать

| Состояние | Текст сейчас |
|---|---|
| Загрузка героев | «Загрузка героев…» |
| Загрузка матчапов | «Загрузка матчапов…» (поверх уже работающего экрана) |
| Пустой драфт | «Выберите хотя бы одного вражеского героя.» |
| Ошибка API | «OpenDota временно недоступен (522)» + кнопка «Сбросить кэш и повторить» |
| Лимит запросов | «OpenDota: превышен лимит запросов, попробуйте через минуту» |
| Ничего не найдено в поиске | «Ничего не найдено» |
| Нет требований к закупу | «Особых требований к закупу нет — берите стандартный билд.» |

Загрузка матчапов происходит **после** того, как пользователь уже выбрал героя, и
список рекомендаций в этот момент уже показан со старыми данными. Нужно состояние
«обновляется», а не подмена экрана спиннером.

## 9. Ассеты

- Портреты героев: `https://cdn.cloudflare.steamstatic.com` + путь из API,
  **256×144**, соотношение 16:9. Других размеров нет — под другие пропорции придётся
  кадрировать.
- Иконки предметов: тот же CDN, **88×64**.
- Своих иллюстраций нет и заводить не планируется.
- Шрифт — системный стек. Кастомный шрифт возможен, но это +100–300 КБ к загрузке
  внутри Telegram, где приложение открывают на мобильном интернете.

---

## 10. Чего делать не нужно

- Своей шапки с логотипом и названием — её перекрывает хедер Telegram.
- Splash-экрана, онбординга, туториала — у пользователя 30 секунд.
- Анимаций появления карточек, параллакса, плавных раскрытий дольше 150 мс.
- Иконок в стиле игры (золото, свитки, фэнтези-рамки) — они съедают место
  и замедляют чтение чисел.
- Модальных окон поверх модальных.
- Графиков и диаграмм сверх трёх полос вклада.

---

## 11. Что важнее всего

Если придётся чем-то жертвовать, порядок приоритета такой:

1. **Скорость считывания ответа** «кого брать» — топ-3 карточки.
2. **Скорость выбора героя** — шторка A5.
3. **Понятность «почему»** — три полосы вклада.
4. **Блок «против драфта соперника»** на билдах.
5. Всё остальное.
